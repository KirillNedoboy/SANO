# SANO v0.3.0 release notes (prepared, not published)

These notes prepare a local release boundary for SANO `0.3.0`, covering work
after the published `v0.2.0` tag. They are not a GitHub release or tag. Publish
only after the SANO candidate has been reviewed, integrated, and validated on
public `main`.

## Highlights

- A self-hosted personal and family health workspace with explicit Person
  scope, family authorization, health records, visits, and recovery.
- Person-scoped document originals in PDF, TXT, JPG, and PNG, with provenance
  and bounded local Russian/English OCR for images and scanned PDFs.
- Optional document descriptions and Q&A over selected recognized text and
  page references, with explicit per-action consent and execution receipts.
- Reusable agent-trust contracts, portable schemas, provider identities,
  deterministic evaluations, and an inspectable audit boundary.

## Safety and privacy

Human review controls promotion of candidate facts into canonical records.
External model disclosure is optional and limited to selected evidence after
per-action consent. Raw genome data never enters supported provider context.
Local inference is available; the model identifier and hardware benchmark
results are not part of this prepared release evidence.

SANO is not clinically validated software, an AI doctor, a diagnostic or
treatment authority, a dosage recommender, or a medication start/stop
authority. No public SaaS readiness or Sentient confidential-compute
integration is claimed.

See [SANO live validation](../sano-live-validation.md) for the checked CI and
operator-confirmed test evidence. Do not infer a public release until an
explicit `v0.3.0` release is created.
