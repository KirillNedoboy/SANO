# SANO v0.3.0

SANO v0.3.0 is the current open-source release of the SANO self-hosted personal and family health workspace.

This release consolidates the product, document-understanding, family-access, agent-trust, validation, and production-readiness work completed since v0.2.0.

## Highlights

- Self-hosted personal and family health workspace with explicit Person scope, family authorization, health records, visits, and recovery.
- Person-scoped document originals in PDF, TXT, JPG, and PNG with provenance and bounded local Russian/English OCR.
- Optional document summary and Q&A over selected recognized text and page references, with explicit per-action consent and Execution Receipts.
- Provider-independent guarded AI runtime with deterministic validation and portable agent-trust contracts.
- Reusable trust infrastructure including schemas, provider identity checks, deterministic evals, Agent Skills interoperability, and audit boundaries.
- Production validation for the OpenRouter/DeepSeek path, including document summary, document Q&A, citations, attribution, and Execution Receipts.

## Safety and privacy

Human review controls promotion of candidate facts into canonical records.

External model disclosure is optional, limited to selected evidence, requires explicit per-action consent, and produces an Execution Receipt.

Raw genome data does not enter supported provider context.

SANO is not clinically validated software, an AI doctor, diagnostic authority, treatment authority, dosage recommender, or medication start/stop authority.

No public SaaS readiness, existing production Sentient integration, or already-implemented confidential-compute integration is claimed by this release. SANO remains a self-hosted workspace and trust foundation under the boundaries stated above.
